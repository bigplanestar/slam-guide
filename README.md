# SLAM 阶梯式学习指南（网页版）

在线阅读：https://bigplanestar.github.io/slam-guide/

由《激光定位与 SLAM 五个问题：从基础推导到工程实践》重新整理：按难度分为 10 级、42 章，配 52 个动画演示，每章附一个动手练习。

- 左侧目录按难度阶梯排列，顶部可全文搜索
- 动画可暂停、拖动进度、逐帧查看和 0.5 倍慢放
- 选中正文文字可以直接高亮（黄 / 绿 / 蓝 / 粉）、加粗或加下划线；点已有标记可改样式或删除，笔记面板的“划线”页汇总全部标记
- 每章末尾有一个动手练习（Python + numpy），给出数据和预期输出，参考实现折叠在练习末尾，可一键复制
- 可按小节记笔记，或选中正文文字引用后记笔记，支持“重点 / 疑问 / 心得”标签
- 可标记每章“已学完”，显示学习进度
- 笔记、划线和进度保存在当前浏览器里；换设备时用笔记面板的“导出/备份”导出 `.json`，在另一台设备上“从备份文件恢复”
